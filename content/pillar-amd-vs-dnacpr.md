## H1: AMD vs DNACPR：同樣關於「不急救」，但完全不同的兩回事

> 副標：一個是自己預先決定的指示，一個是醫生在現場的判斷。搞清楚分別，才不會在關鍵時刻搞錯。

## 1. 一句話分清楚

| | 預設醫療指示 (AMD) | 不作心肺復甦術命令 (DNACPR) |
|---|---|---|
| **誰決定？** | 你自己（預先簽署） | 醫生（經共識後發出） |
| **拒絕什麼？** | 任何維持生命治療（CPR、呼吸機、洗腎等） | 只拒絕心肺復甦術（CPR） |
| **何時生效？** | 你失去能力 + 符合指定疾病條件 | 心臟/呼吸停止時 |
| **由誰簽署？** | 你 + 兩位見證人（一位醫生） | 主診醫生 + 專科醫生（兩位醫生） |
| **法律基礎** | 《條例》第651章 | 《條例》+ 醫管局臨床指引 |

## 2. 詳細比較

### AMD（預設醫療指示）——你自己決定

AMD 是你**在有精神能力時**，為將來的自己做的一個決定。

- 你可以選擇拒絕**一種或多種維持生命治療**（CPR、呼吸機、洗腎、抗生素、人工營養等）
- 只有在指定疾病情況（末期病、植物人、其他晚期不可逆轉疾病）才會生效
- 只需要**一位註冊醫生見證**（我們的醫生）
- 適合：想全面掌控醫療安排的人

### DNACPR（不作心肺復甦術命令）——醫生決定

DNACPR（Do Not Attempt Cardiopulmonary Resuscitation）是一份由**醫生發出**的臨床命令，指示當病人心跳或呼吸停止時，不進行心肺復甦術急救。

- 只針對 CPR，不涉及其他治療
- 由主診醫生與家人共識後簽發
- 需要**兩位醫生簽署**（主診醫生 + 專科醫生）
- 適合：病情已到末期，急救只會延長痛苦的患者

## 4. 兩者的關係：可以同時有嗎？

**可以。而且很多人兩樣都會有。**

理想情況下：
1. 你先簽署 **AMD**，清楚列明你拒絕哪些治療（包括 CPR）
2. 如果入住醫院，醫生會根據你的 AMD 發出 **DNACPR 命令**
3. DNACPR 是醫生在臨床環境中的執行工具，AMD 是你的意願聲明

**簡單講：AMD 是你的「遺願」，DNACPR 是醫生根據你的遺願發出的「執行命令」。**

## 5. 實際場景

### 場景 A：只有 AMD，沒有 DNACPR
陳伯簽了 AMD，拒絕 CPR。他在家中離世，情況是末期癌症。因為不在醫院，不需要 DNACPR——家人出示 AMD，醫生確認情況符合，自然離世。

### 場景 B：只有 DNACPR，沒有 AMD
張婆婆在醫院，醫生認為急救對她無意義，與家人商量後發出 DNACPR 命令。她只拒絕 CPR，其他治療（如抗生素、輸液）仍會繼續。

### 場景 C：兩樣都有
李生在健康時簽了 AMD（拒絕 CPR、呼吸機和洗腎），入住醫院後醫生根據他的 AMD 發出 DNACPR 命令。當他心跳停止，醫生不進行 CPR；當他需要洗腎時，醫生也根據 AMD 停止透析。

## 6. 哪個適合我？

| 如果你… | 建議 |
|---------|------|
| 健康、想提前規劃 | ✅ 先簽 AMD |
| 已確診末期病 | ✅ AMD + DNACPR 兩樣都安排 |
| 家人已住院、醫生建議不急救 | ✅ DNACPR（由醫生處理） |
| 不清楚自己想要什麼 | ✅ 先諮詢醫生，了解 AMD 內容 |
| 只想拒絕 CPR，其他治療照常 | ✅ 可考慮只簽 Form 2（只拒 CPR） |

## 7. AMD vs DNACPR vs 平安三寶

很多人會把 AMD 和「平安三寶」混淆。其實「平安三寶」是三個獨立文件的統稱：

| 文件 | 用途 | 我們提供？ |
|------|------|-----------|
| **AMD（預設醫療指示）** | 拒絕維持生命治療 | ✅ 醫生上門簽署 |
| **EPA（持久授權書）** | 委託他人處理財務 | ⚠️ 可配合 |
| **遺囑/平安紙** | 分配遺產 | ❌ 建議找律師 |

我們專注 AMD，因為這是醫療專業——我們是醫生，不是律師。

## 8. 總結：一個表格全看清

| 項目 | AMD | DNACPR |
|------|-----|--------|
| 決定者 | 你自己 | 醫生 |
| 拒絕內容 | 多種 LST（可自選） | 只有 CPR |
| 生效條件 | 末期病/植物人/晚期疾病 | 心臟或呼吸停止 |
| 簽署方式 | 你 + 2位見證人（1位醫生） | 2位醫生簽署 |
| 修改/撤銷 | 隨時可改 | 醫生可更新 |
| 適用場景 | 在家中或院舍 | 主要在醫院 |
| 法律效力 | 新條例 Cap.577 | 臨床命令 + Cap.577 |
| 費用 | 醫生上門收費透明 | 醫院安排，不需額外付費 |
