## H1: 什麼是預設醫療指示 (AMD)？讓你的醫療意願，即使無法開口也能被尊重

> 副標：2026年7月生效的新法例，讓你可以提前決定——當自己昏迷或末期病時，接受或不接受哪些維持生命治療。

---

## 1. 簡單講：AMD 是什麼？

**預設醫療指示（Advance Medical Directive，簡稱 AMD）** 是一份法律文件，讓你在精神健全、有自主能力的時候，預先寫低：如果將來因為末期疾病、持續植物人狀況或其他指定情況而失去表達能力，你拒絕接受哪些維持生命治療。

用一句話說：**「如果將來我無得救，請唔好幫我吊命。」**

AMD 不是遺囑（平安紙），不是安樂死，也不是放棄治療。
AMD 是讓你的醫療意願——在你自己無法開口時——依然能夠被尊重。

---

## 2. AMD 的背景：為什麼現在需要知道？

2024年11月20日，香港立法會通過了 **《維持生命治療的預作決定條例》（第651章）**，並將於 **2026年7月31日正式生效**。

這條法例的意義：
- 將 AMD 從普通法（common law）提升到成文法（statutory law）保障
- 為醫生和簽署人提供明確的法律框架
- 讓「預設醫療指示」在香港有明確的法律效力

在此之前，香港的 AMD 處於法律灰色地帶，醫生執行時有法律責任的顧慮。新條例解決了這個問題。

---

## 3. AMD 涵蓋什麼治療？

AMD 只針對 **維持生命治療（Life-sustaining Treatment, LST）**，即那些用來延長生命但無法根治疾病的醫療程序。你可以拒絕以下全部或部分治療：

| 治療 | 說明 |
|------|------|
| 心肺復甦術 (CPR) | 心跳或呼吸停止時的心外壓、電擊、插喉 |
| 人工呼吸機 | 當無法自行呼吸時，用機器代呼吸 |
| 人工營養及液體補充 | 用喉管餵食或補充水分 |
| 血液透析（洗腎） | 腎功能衰竭時的血液過濾 |
| 抗生素治療 | 治療感染的藥物 |
| 深切治療（ICU） | 住進加護病房 |

**重要：** AMD 不代表「乜都唔醫」——你仍然會接受舒緩治療（palliative care），例如止痛、處理症狀、心理支援等，以保持生活質素。

---

## 4. 三種觸發 AMD 生效的情況

新條例訂明，AMD 只有在以下三種情況才會生效：

### ① 末期疾病（Terminal Illness）
醫生確認病情不可逆轉，並且在合理預計下死亡即將來臨。

### ② 持續植物人狀況 / 不可逆轉昏迷（PVS / Irreversible Coma）
病人失去意識，沒有恢復的可能。

### ③ 其他晚期不可逆轉生存受限疾病（Other Advanced Irreversible Life-limiting Conditions）
例如：晚期認知障礙症（ dementia）、末期器官衰竭（心、肺、腎、肝）等。

**只有在上述情況，醫生才會執行你的 AMD。如果你只是暫時昏迷或可逆轉的病情，AMD 不會生效，醫生會照常急救。**

## 5. 誰可以簽署 AMD？

| 條件 | 說明 |
|------|------|
| 年齡 | 年滿18歲 |
| 精神能力 | 在簽署時必須精神健全、有能力理解 AMD 的意義 |
| 自願 | 出於個人意願，不受他人壓力 |
| 知情 | 簽署前必須與醫生深入討論各項 LST 的意義 |

## 6. AMD 的簽署流程

### 步驟 1：WhatsApp 諮詢
聯絡我們，醫生會先解答你的問題，確認是否適合訂立 AMD。

### 步驟 2：醫生上門評估
醫生到家中進行精神能力評估（Mental Capacity Assessment），確保你理解 AMD 的內容。

### 步驟 3：簽署文件
- 由你本人在兩名見證人面前簽署
- 第一位見證人必須是香港註冊醫生（我們的醫生）
- 第二位見證人是任何成年人（可以是家人或朋友）
- 見證人不得從你的遺產中得益

### 步驟 4：保管文件
簽署後的 AMD 正本由你保管，我們建議讓信任的家人知道文件的位置。

### 隨時可以撤銷
只要你仍然精神健全，你可以隨時撤銷 AMD——最簡單的方法就是撕毀文件。口頭撤銷在有見證人的情況下也有效。

## 7. AMD 與安樂死有什麼分別？

這是最多人誤解的地方。

| | 預設醫療指示 (AMD) | 安樂死 (Euthanasia) |
|---|---|---|
| 目的 | 拒絕接受治療 | 主動終結生命 |
| 誰執行 | 醫生停止或不開始治療 | 醫生注射藥物終結生命 |
| 香港法律 | ✅ 合法（2026年7月生效） | ❌ 違法 |
| 場景 | 末期病、植物人等 | 不論病情 |
| 結果 | 自然死亡 | 人為終結 |

**AMD 不是安樂死，也不是「幫你去死」。AMD 是「讓你可以自然地走，不被機器吊住。」**

## 8. 誰應該考慮簽署 AMD？

- **末期病人** — 希望在家離世，不想在醫院被急救
- **長者** — 想提前為晚年做準備
- **認知障礙症早期患者** — 趁還有能力時訂立
- **長期病患者** — 心臟病、腎衰竭、癌症等
- **注重規劃的人** — 想讓家人不用為醫療決定而煩惱
- **任何年滿18歲的人** — 你永遠不知道明天會發生什麼

> 💡 **一句話記住：** AMD 不是寫給自己，是寫給將來無法說話的自己。

## 9. 常見問題（FAQ）

### Q: AMD 與遺囑（平安紙）有什麼分別？
AMD 處理醫療決定。遺囑處理財產分配。兩者有各自的法律基礎，可以分開簽署。

### Q: 簽署 AMD 後可以改嗎？
可以。只要你精神健全，可以隨時撤銷或重新簽署更新版本。

### Q: 在外地簽署的 AMD 在香港有效嗎？
如果符合《條例》的條件，在外地簽署的 AMD 在香港也有效。但建議在香港重新簽署以確保無法律風險。

### Q: 我不識字，可以簽 AMD 嗎？
可以。我們會有醫生詳細解釋內容，你可以在見證人面前用指模或標記簽署（具體安排視乎法律要求）。
